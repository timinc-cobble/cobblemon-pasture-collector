## What if…

…you could put Pokémon to work when they’re in the Pasture Block?

## Features

- Adds a Pasture Bin.
  - Collects drops from Pokémon in immediately adjacent Pasture Blocks.
  - Has a 4-slot inventory that can only be extracted from.
  - Works with hoppers and other extraction tools.
- Adds a new Drop Loot Tables dropper, with full support!
  - An optimized, optional per-dropper cooldown to boot.

## Dependencies

- [Cobblemon](https://www.notion.so/Cobblemon-22157e0d4afd80a49896c70a775a3c7f?pvs=21)

- [Drop Loot Tables](https://www.notion.so/Drop-Loot-Tables-21d57e0d4afd80809bbbf3c38975664e?pvs=21)

## Testing

Give yourself a Pidgey. Put it in a PC. Add it to a Pasture Block. Place a Pasture Bin next to it. Run `/gamerule randomTickSpeed 3000` and watch as little green flecks go on above the bin, then open it by interacting with it to see the drops.
